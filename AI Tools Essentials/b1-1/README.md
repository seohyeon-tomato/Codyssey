> Codyssey AI Tools Essentials · GenAI 기초 1: LLM 기반 업무 자동화

| 항목 | 내용 |
|---|---|

| 비교 모델 | ChatGPT / Claude / Gemini |

## 프로젝트 개요

홈바 입문자나 작은 바 운영자가 고객의 취향, 알레르기, 원하는 도수와 보유 재료를 매번 대조해 칵테일을 추천하려면 시간이 걸린다. LLM에 단순히 “칵테일을 추천해 줘”라고 입력하면 없는 재료를 넣거나, 표준 레시피와 변형 레시피를 구분하지 않거나, 알레르기와 음주 가능 여부를 놓칠 수 있다.

이 프로젝트는 입력 조건을 구조화하고, 정보가 부족하면 먼저 질문하며, 검증되지 않은 사실은 단정하지 않는 프롬프트를 설계한다. 최종 결과는 추천 후보 3개, 제조 가이드, 대체 재료, 주의사항과 SNS 문구까지 재사용 가능한 형식으로 출력한다.

### 자동화 목표

- 고객 조건에 맞는 후보 3개를 제안한다.
- 보유 재료만으로 가능한 레시피와 추가 재료가 필요한 대안을 구분한다.
- 필수 정보가 부족하면 추천 전에 최대 3개의 확인 질문을 한다.
- 표준 레시피와 홈바용 변형을 구분하고, 검증하지 못한 사실·수치는 `확인 필요`로 표시한다.
- 10턴 이상 대화에서도 확정 조건과 변경된 조건을 구분해 유지한다.

## 핵심 개선 내용

v1은 짧고 자율성이 높았지만 출력 형식과 안전 규칙이 명시적이지 않았다. v2는 규칙과 Few-shot을 추가했지만, 예시의 짧은 출력 모양이 7개 섹션 출력 지시와 충돌하면서 오히려 일부 결과가 퇴행했다.

v3에서는 충돌하는 예시 출력을 제거하고 다음을 명확히 분리했다.

- 안전·금지 조건과 최신 변경 사항의 우선순위
- 첫 추천의 전체 출력 형식과 후속 턴의 간결한 출력 형식
- 재료 추가·삭제, 논알콜 전환을 반영하는 대화 상태 관리
- 정확한 ABV나 표준 레시피를 확인하지 못했을 때의 불확실성 표시

상세한 전후 비교와 프롬프트 전문은 [시스템 설계 문서](docs/02-system-design.md)에서 확인할 수 있다.

## 미션 통과용 MVP와 포트폴리오 확장

### 미션 통과용 MVP

- 3개 모델의 실행 환경과 동일 입력을 기록한다.
- 최소 4개 평가 축에 점수와 관찰 근거를 남긴다.
- 시스템 설계, Few-shot 3개, v1·v2 전후 비교를 제시한다.
- 사실 기반 질문 5개와 Pass/Fail 결과를 기록한다.
- 한 대화창의 10턴 이상 원문과 문맥 유지 판정을 남긴다.

### 포트폴리오용 추가 기능

- 실제 입력 폼과 결과 화면을 가진 간단한 웹 데모
- v1·v2·v3 결과 차이를 한눈에 보는 시각 자료
- 실행 화면 캡처와 재사용 가능한 프롬프트 복사 영역

추가 기능은 선택 사항이며, 현재는 실제 테스트 로그를 완성하는 것이 우선이다.
